# Project Overview

## Project Name

PETROPULSE – Baghewala Reservoir Digital Twin

## Introduction

PETROPULSE is an interactive digital twin dashboard developed to
visualize and monitor important parameters of an oil production well.

The system provides a digital representation of the well condition
through an easy-to-use dashboard interface.

## Problem Statement

Monitoring different well parameters separately can make it difficult
to understand the overall condition of a production well.

PETROPULSE provides a centralized dashboard where important parameters
can be viewed and monitored in one place.

## Main Parameters

The dashboard currently focuses on:

- Temperature
- Viscosity
- Pressure
- SRP Status
- Well Profile
- Production-related information

## Key Features

- Interactive dashboard
- Changeable well parameters
- Visual data representation
- Live well profile graph
- Current well state monitoring
- Dark-themed professional interface

## Technology

The current prototype is developed using:

- HTML
- CSS
- JavaScript
- Chart.js

## Current Project Status

The current version is a frontend prototype.

The architecture is designed so that real-time sensor data,
database connectivity and advanced analytics can be added in
future versions.
